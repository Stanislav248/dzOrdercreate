# Проєкт: OrderApp (ASP.NET Core MVC / Web API)
- Стек: .NET 8 / .NET 9, ASP.NET Core Controllers.
- Сутність: Order (Id, Title, Description, Price, Quantity, TotalPrice).
- Валідація: Title (3-50 знаків, обов'язкове), Price (1-10000), Quantity (1-100).
- Правило: Поле TotalPrice обчислюється автоматично на основі Price * Quantity.

## Інструкції для кодування:
1. Завжди перевіряй ModelState.IsValid у POST запитах.
2. Не передавай TotalPrice через JSON/DTO, це обчислювана властивість.
3. Для тестування використовуй наявний In-Memory список замовлень у контролері.
